## My approach to using AI

**1. Read first**
- I read the README and BRAND.md before asking the AI anything and also give AI the prompt to brief it out for understanding.
- I used the original page like a shopper(user) and wrote down the bugs I found.

**2. Ask for one thing at a time**
- I did not ask for everything in one go. I would fix the cart first, then the coupon, then search, then the delivery check.
- In every prompt I gave the rules and the constraints, like "do not change the API block".
- After each answer, I tested it in the browser before moving on.

- I clicked everything myself. This is how I found the stretched images and the missing spacing.
- I asked the AI to check its own work against BRAND.md and list anything that breaks a rule.

**3. Images**
- I made one product image first and checked it.
- I have used images of product directly generated by Gemini.
- Then I used the same style line for the other so they match.
